| Retirement and rollback | disabled activation manifest; preserve evidence | No destructive reset and no reference/Vue runtime dependency |

The current phase installs only Email and Telegram modules. A capability absent from the compile-time assembly has no navigation, route, fixture, bridge operation, or backend handler. Provider connection and live send remain separate, action-specific approval gates.

The final production entry is activation-off by default. Explicit synthetic preview uses local deterministic clients. The governed bridge activation accepts opaque mutation and snapshot/control ports; it does not place a process capability or endpoint in serializable browser state. The guarded runtime remains an explicit, loopback-only start and is not imported by the browser bundle.
